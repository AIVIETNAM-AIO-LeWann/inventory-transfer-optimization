# Inventory Transfer Optimization

A Streamlit application for analyzing retail inventory and recommending
product transfers between stores.

## Current status

The project is under development.

## Main features

- Sample retail data generation
- Inventory shortage and excess analysis
- Rule-based transfer optimization
- Linear programming optimization
- Genetic algorithm optimization
- Interactive Streamlit interface
